func FermatFactors

func FermatFactors(n uint) []uint

FermatFactors finds a pair of factors of n using Fermat's factorization method. Parameter n is the number to factorize. Returns a slice of two factors: {2, n/2} for even n, or {a-b, a+b} for odd n where n = a^2 - b^2.

func TrialDivision

func TrialDivision(n uint) ([]uint, error)

TrialDivision factors n using the trial division method. Parameter n is the number to factorize (must be greater than 1). Returns a slice of prime factors in ascending order, or an error if n is less than 2.
